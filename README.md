# 💪 Kings Fitness Slot Booking App

This is a simple gym slot booking interface where clients can:
- Book a session
- Pick time slots
- Get visual feedback

### 🔥 Features
- Clean UI with animations
- Font Awesome icons
- Responsive layout
- JS Promises used to simulate slot check


---

### 🛠 Built With
- HTML5
- CSS3 (Linear gradient + animation)
- JavaScript (ES6)
- Font Awesome
